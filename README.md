## Current Focus

**Chapter 1: Python Foundations — Week 4, Lesson 4: Conditional Logic**

I'm learning how to use comparisons and `if`, `elif`, and `else` to make decisions in Python. My current practice checks whether an account balance is above, at, or below a minimum balance. The Monthly Budget Health Checker is my next mini-project in this lesson.

## How I'm Learning

I learn one concept at a time and apply it to practical finance examples. My learning process includes:

1. Study the lesson and work through practice examples.
2. Build small projects using the concepts I've learned.
3. Combine those skills in an end-of-lesson project.
4. Review the calculations and understand how changing inputs affects the results.

My projects focus on budgets, income, expenses, savings goals, and investment calculations as I build a foundation for larger financial tools.
